## Entry

The program writes a single line to `$MAKEFUN_OUTPUT_DIR/entry.txt`:

```
Out of office. Out of water. Out of patience. The fern has left the building.
```

- 77 characters, one line, UTF-8, no trailing newline.
- `entry.txt` SHA-256: `25adb8e4fd0ff86f99b6b85e2e4c537f1f183d69b40819123eda4e2e31e3f749`

## How to run

```bash
MAKEFUN_OUTPUT_DIR=output python3 main.py
```

This writes `output/entry.txt` and prints the path, byte count, and SHA-256. The program validates the gate (one line, 1–120 characters, not only whitespace) and reads the file back to confirm the bytes match.
